# Claims, activos y gates de publicación

## Publicables

| Elemento | Uso permitido |
|---|---|
| Fundadora y presidenta de la CCI Brasil–Panamá | Uso directo; respaldado por el registro de claims y fuentes institucionales/legislativas |
| Socia de StepUp & Company | Usar `socia/partner`; no fijar `COO`, `Country Chair` o `Founding Partner` hasta ratificación corporativa |
| Investor Lifestyle, 8 de octubre de 2025 | Usar como aparición editorial y pensamiento publicado |
| Telemetro y Quijano & Associates | Usar como contexto público del PBID 2025, sin ampliar la responsabilidad personal de Nina |
| Instagram, YouTube, LinkedIn y newsletter | Usar como canales propios de distribución, no como validación independiente |

## Condicionados o bloqueados

| Elemento | Regla |
|---|---|
| Logos de embajadas, Gobierno de Panamá y MICI | No presentarlos como aval personal; exigir contexto, permiso y regla de reproducción |
| Invitación CNI / CAF | Archivar documento, fecha, destinatario y permiso antes de publicar; una invitación no equivale a endorsement |
| Startup Summit / Sebrae | No publicar ningún documento marcado `Confidencial` |
| Certificación Board | Bloqueada hasta identificar institución, programa, fecha y certificado/badge verificable |
| FGV | Puede atribuirse al perfil propio como Gestión Estratégica de Carbono, 2022; no convertirla en especialidad de inversión o carbono |
| Seguidores y suscriptores | No publicar cifras hasta verificarlas en la fecha de lanzamiento |
| Fotografías | Confirmar autor, titular, personas visibles, canales, territorio, plazo y aprobación |
| Colaboraciones de marca | Presentar como territorio futuro; no inventar acuerdos, clientes o campañas |

## Gates separados

1. **Ready in Codex:** código, build, tests y QA visual completos.
2. **Saved in GitHub:** remoto GitHub correcto, commit aprobado y SHA verificado.
3. **Online in Hostinger:** repositorio/branch/root correctos, dominio, SSL, assets y responsive verificados en producción.
4. **Indexable:** derechos, privacidad, analítica, Search Console y claims aprobados; solo entonces retirar `noindex`.
